# Day 1 - Introduction to JavaScript

## Overview

Today marked the beginning of my JavaScript learning journey. The focus was understanding how JavaScript code executes and how output is displayed using `console.log()`.

---

## Code Covered

```javascript
console.log("Gaurav")
console.log("hi everyone!wassup?")
console.log(2+3)
console.log("My JavaScript journey begins!")
```

---

## Understanding console.log()

The `console.log()` function is used to display output in the console.

```javascript
console.log("Hello World")
```

Output:

```text
Hello World
```

---

## Printing Text

Strings are written inside quotes.

```javascript
console.log("Gaurav")
```

Output:

```text
Gaurav
```

---

## Printing Calculations

JavaScript can perform calculations directly.

```javascript
console.log(2+3)
```

Output:

```text
5
```

---

## Real World Usage

Developers use `console.log()` to:

* Check variable values
* Debug programs
* Verify calculations
* Understand code execution flow

Example:

```javascript
let age = 20
console.log(age)
```

---

## Key Learnings

* JavaScript executes statements from top to bottom.
* `console.log()` is used for output.
* Strings are enclosed in quotes.
* JavaScript can evaluate mathematical expressions.

## Interview Points
